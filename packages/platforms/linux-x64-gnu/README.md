# @thumbcraft/linux-x64-gnu

Prebuilt native `thumbcraft` binary for **Linux x64 (glibc)**.

This package is installed automatically, as an optional dependency, by [`thumbcraft`](https://www.npmjs.com/package/thumbcraft), the document thumbnail generator for Node.js (DOCX, XLSX and PPTX to PNG, JPEG or WebP). Do not depend on it directly: install `thumbcraft` instead.

The binary lives in `bin/thumbcraft`. Source and documentation: https://github.com/klawdyo/thumbcraft
